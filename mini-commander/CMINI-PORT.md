# mini-commander built by cmini

Source: mini-commander by Tomáš Matějíček (upstream `Tomas-M/mini-commander`),
copied unchanged from the clone in `/abc/tiny/_import/mini-commander` (HEAD
`f5024ed`) and then ported here. The GPL license and the upstream README are kept.

## Build

```sh
make mc        # gcc (original build)
make mc-cmini  # cmini (../cmini/cmini.bin -c per file) + glibc + ncursesw
```

`cmini/cmini_libc.h` is generated by `cmini/gen_libc.py` from the glibc and
ncursesw headers (needs gcc only for preprocessing; cmini does not use gcc).
cmini sees only that header (`-I cmini`, no system headers), so every declaration it
needs is in the generated file. Regenerate with `python3 cmini/gen_libc.py`.

## Changes from upstream (so that cmini accepts the sources)

- 8-bit text only (also for a VGA text console): no `wchar_t`, `mbstate_t`,
  `setlocale`, `get_wch`, `setcchar`. A byte is a cell; bytes outside 32..126 are
  shown as `.` (file names with UTF-8 are shown as dots). Typed text: 7-bit only.
- No GNU statement expressions and no compound literals: `SHORTEN` and `SPRINTF`
  return a ring of eight static buffers; `format_text` is a macro over `snprintf`;
  constant string lists are static arrays; struct values are filled field by field.
- No varargs definitions (`format_text` is a macro), no flexible array members
  (`char text[1]`), no function-pointer comparisons (move across filesystems sets
  `operationContext.copy_step` instead).
- Struct tags are used through typedefs `X_t` (`stat_t`, `timeval_t`, `FileNode_t`,
  ...) because cparser does not accept a bare `struct X` in function bodies; the tag
  `stat` became `stat_s` (it collides with the function `stat`).
- `screen` (global) renamed `mc_screen` (it collides with the ncurses name).
- Linux-only `renameat2` path and the `linux/fs.h` include are not used.

The ToaruOS patch of `mc-toaru` is not applied here.

## Checks

Pseudo-terminal tests (both builds behave the same): panels and buttons are drawn,
F7 creates a directory, F3 views a file, F4 edits it and F2 saves it to disk,
F10 exits.
